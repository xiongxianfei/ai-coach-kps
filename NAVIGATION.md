# Navigation and independent reading

## Key takeaway

Use the Practice that answers the present task; links provide depth rather than missing instructions.

## Summary

The package uses ordinary UTF-8 Markdown links, stable metadata IDs and conservative heading fragments. A stable ID is not an anchor.

## Reading routes

[Practice map](PRACTICE-MAP.md) is the learner entry. [INDEX](INDEX.md) lists academic objects by role. [EVIDENCE-MAP](EVIDENCE-MAP.md) traces source support and application limits. [TERMINOLOGY-MAP](TERMINOLOGY-MAP.md) records canonical naming. [REVIEW-QUEUE](REVIEW-QUEUE.md) identifies remaining inspection and evaluation.

## Link procedure

1. Prefer a relative file link for an entire object.
2. For a stage, include the full lowercase heading fragment, such as #stage1-define-a-learning-goal-and-constraints.
3. After renaming a heading, update the stage map, metadata and incoming links together.
4. Test the actual reader when rendering matters; structural validation is not a click test in every Markdown application.

The generated graph is a dependency view, not a model of human cognition or a compulsory reading sequence. No plugin or iframe is required.
