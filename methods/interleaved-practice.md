# Interleaved Practice

## Key takeaway

Mix previously introduced problem types so the learner must select an appropriate approach from the problem itself, then distinguish selection errors from execution errors.

## Summary

Interleaved practice places different problem types within a practice sequence. Rohrer, Dedrick and Stershic studied this arrangement in seventh-grade mathematics, with instruction, mixed assignments and correction. This Method adapts that operation to bounded adult practice; it does not assume the same effects in every subject.

## Use when and prerequisites

Use this when the goal includes deciding which rule, concept or procedure applies. The learner needs enough prior instruction to attempt the included types. Prepare checked problems, acceptable approaches and feedback. If every type is unfamiliar, introduce them before using a mixed set to assess selection.

## Rationale and procedure

A block of one type can reveal the required procedure before the learner reads a problem. Mixing types removes that shortcut. The published arrangement also spreads repeated types over time, so its outcomes do not isolate discrimination from spacing.

1. Select types that the learner needs to distinguish and that have already been introduced.
2. Arrange a mixed sequence without headings that disclose each required strategy. Retain enough problem information to make the task answerable; removing useful context is not interleaving.
3. Have the learner attempt each problem, choosing an approach before executing it. Inspect original work before showing corrections.
4. Check both the choice and its execution. Explain the relevant feature when the method was wrong; address calculation or implementation when the chosen approach was appropriate.
5. Use a fresh mixed set later to inspect independent selection. Return to explanation or a focused example if a type was not understood.

Explicit choice records, the error categories and the return-to-instruction rule are authored adaptations. They help decide what to change without treating every wrong answer as the same difficulty.

## Worked application

**Constructed example:** A learner has been taught the difference between a percentage change and an absolute change. Mix these prompts without naming their categories:

| Prompt | Evaluator's criterion, withheld until after the attempt |
|---|---|
| A fee rises from £40 to £50. By what percentage did it rise? | Divide the £10 increase by the original £40: 25% |
| A fee rises from £80 to £92. How many pounds were added? | Subtract the original amount: £12 |
| A fee falls from £60 to £45. By what percentage did it fall? | Divide the £15 reduction by the original £60: 25% |

The learner can briefly identify the requested quantity before calculating. Answering “£10” to the first prompt may indicate confusing the requested quantity; calculating `10 / 40` incorrectly instead suggests an execution issue. Inspect the actual work rather than inferring the cause from the numeral alone.

Follow with new prices in a less predictable order, including consecutive problems of one type where useful. A rigid alternating pattern could become another cue. The sequence and monetary example are authored illustrations, not the study materials or a reported learner result.

## Output and validation

Produce a checked mixed set, preserved choices and solutions, feedback, and a later independent check where needed. Success requires appropriate selection and execution on fresh cases. A polished corrected worksheet is not independent evidence. If selection remains poor, inspect whether headings, surface cues or the wording taught an unintended shortcut.

## AI role and limits

AI can draft the mixture, flag accidental cues and classify candidate error patterns. Verify every problem and accept alternative valid solutions. The learner chooses the approach; AI should not name the formula before the attempt when selection is being assessed.

Mixing unrelated subjects at random does not necessarily exercise a useful distinction. There is no prescribed mixture ratio here. [Spaced Repetition](spaced-repetition.md) schedules revisits; [Worked Example Instruction](worked-example-instruction.md) alternates demonstration and learner work. Those operations can coexist with category mixing but are not interchangeable.
