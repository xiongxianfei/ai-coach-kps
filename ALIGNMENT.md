# Academic source alignment

## Key takeaway

Use established meanings in the supporting library and put original AI application decisions in Practices.

## Summary

This domain explicitly adopts the professional-alignment approach of KPS Core 10.2.0. Its additional declarations are curation policy, not changes to the KPS 9.x language or evidence that scholarship endorses KPS.

## Admission by role

| Role | Admission basis | Not sufficient |
|---|---|---|
| Concept | Located scholarly characterization or definition | A fashionable term with an unrelated citation |
| Principle | Scoped empirical result or supported methodological relationship | A normative coaching rule written as a declaration |
| Model | An identified published representation, with a faithful subset and limits | A newly invented coaching cycle given a theorist's name |
| Method | A recognizable published operation and inspected procedural basis | An original prompt chain presented as a validated intervention |
| Practice | Explicit KPS application synthesis with usable actions | A list of links or a claim that it was empirically tested |

No standalone original workflow Models or Methods are included. Local prompt contracts, aid categories and record schemas are specifications or Practice content. They are not scientific Principles.

## Alignment records

Each non-Practice object declares source_alignment with a Reference ID, a documentation relation and an actual passage locator. Allowed relations are definition-paraphrase, scoped-empirical-finding, methodological-relationship, published-model-subset and published-procedure-summary. The published-model-subset relation explicitly describes an academic framework rather than a standards-body model; this is a domain profile, not silent equivalence to Core's standard-model-subset relation.

These declarations do not express formal ontology equivalence. Named sources support meanings only to their inspected extent. Source-defined scope takes precedence over local paraphrase.

## Academic naming

Use source-grounded kebab-case paths and recognized names where faithful. Preserve related-but-different meanings: retrieval is not spacing; metacognition is not all self-regulated learning; self-explanation is generated by the learner rather than supplied by AI. Academic hyphens can remain in canonical_name and prose; display headings follow the conservative Markdown profile.

Pieschl, not Schraw, authored the inspected calibration paper. A generic instruction loop is not Zimmerman's cyclical model. The latter is not included because an original source was not inspected sufficiently for admission.

## Evidence and originality

Each source record states publication identity, access extent, locators, contribution and nonclaims. A theoretical or review source can define a concept without proving an intervention effect. All AI adaptations and prompt wording remain provisional. Normative commitments to consent, privacy and access are policy choices, not invented empirical findings.

## Tests and review

The domain tests check declarations, targets, role relations and explicit limits. They cannot establish faithful paraphrase, adequate evidence or actual learning. No automated promotion to reviewed status is allowed in this draft.
