# Retrieval and Distributed Practice With an AI Coach

## Key takeaway

Separate generating prompts, retrieving before feedback, checking against a source and revisiting at a chosen later time.

## Summary

This Practice combines published retrieval and spacing ideas in an original adult AI-assisted review workflow. It produces checked study items, original recall attempts, correction records and an explicit future plan. The five stages are a recommended route; prior instruction, source access and time availability are prerequisites. AI-assisted item creation is not itself retrieval by the learner.

## Entry and boundaries

Use this Practice for safe conceptual or procedural review with a source that can be checked. The AI may draft prompts or feedback, but the learner does the retrieval. The procedure does not replace skilled instruction, and it is not an established spaced-repetition software algorithm. Retain access accommodations while distinguishing answer assistance.

## One current retrieval target

Start with **one already encountered concept, relation or procedure** and one checked retrieval prompt. Save the response before feedback and distinguish actual recall from an explanation supplied by AI. Additional questions and a spaced review plan may follow, but they are not prerequisites for recording this one attempt. A planned future check is not observed retention. The [lesson and task guide](../guides/learning-workflow.md) clarifies the current output and stop/continue choice without prescribing an optimal interval.

## Stage1 Select learned material and a retention goal

1. Choose **one current concept, relation or procedure** already encountered; optionally expand to a related set after inspecting the first response. If initial understanding is absent, return to instruction rather than trying to recall unknown content repeatedly.
2. Specify what must be retained and when it will be useful. Select recall, explanation or application criteria appropriate to that purpose.
3. Identify a reliable reference and distinguish its claims from your own synthesis. Do not create flashcards around an unchecked AI invention.
4. Plan a manageable study occasion and a separate later check. Exact numbers of items and dates are local choices, not research-validated constants.

Retrieval concerns the activity; distribution concerns when activities occur. Neither term automatically specifies interleaving, difficulty or a repetition algorithm.

Locate each selected question in the [goal-specific concept map](concept-mapping-and-instructional-sequencing-with-ai.md). Include questions about relations and boundaries when relevant, not just isolated node names. Keep the panoramic subject regions as context; do not require retrieving the whole discipline before working on one goal.

## Stage2 Prepare prompts with checked answers

1. Ask the AI to propose **one answerable prompt for the next attempt** anchored to an identified source passage; more prompts may be prepared later if needed. Request explanation and boundary questions when simple term recall would miss the goal.
2. Check that each prompt has an appropriate criterion and is not misleading, overspecific or answer-revealing. Record source locators for the answer key.
3. Keep answers separate from the retrieval display. If checking your own newly generated items has exposed their answers, record that exposure and treat the activity as preparation, not a clean independent test.
4. For consequential evaluation, prefer independently prepared items or human-checked criteria. Multiple AIs agreeing does not establish source independence.

**Example item design**

```text
Recall prompt: State what a per-unit quantity compares.
Explanation prompt: Why must the quantity unit be the same before comparison?
Boundary prompt: When would the lowest unit cost not answer the person's
actual decision question? Keep this reasoning task distinct from advice.
```

These are constructed examples. Model-generated items remain proposals until the learner or a competent person checks them.

## Stage3 Retrieve preserve and correct

1. Put the answer and source aside. Respond before asking the AI for hints; use only the access supports permitted by the intended task.
2. Save the original response, elapsed time when relevant, and uncertainty. An omitted item is missing or not attempted, not automatically scored wrong.
3. Compare the response to the source-based criterion after saving it. Separate errors from acceptable alternative wording and mark unsupported AI judgments for verification.
4. Write a corrected explanation and its basis, but do not overwrite the original. If help is requested before completion, record an assisted attempt instead of pretending it was unaided retrieval.
5. Change the task or return to a worked example when repeated failure reveals insufficient preparation. The goal is learning, not maximizing unproductive difficulty.

**Prompt for the coach**

```text
Present only the next checked question and wait. Preserve my response before
feedback. Afterward, compare it with the supplied criterion and quote its
locator, not an invented source. Mark hints and answer exposure separately.
Do not report a corrected answer as my original independent recall.
```

This is an authored prompt, not an assurance that a model will follow it. Audit what the coach actually supplies.

## Stage4 Distribute review with a revisable schedule

1. Choose separated review occasions that fit the learner's intended use and constraints. Record planned intervals without claiming that one fixed daily pattern is optimal.
2. At each actual occasion, note the time since relevant study and any intervening practice or answer exposure. A missed appointment is not a failed memory test.
3. Adjust the next interval or activity from the observed item-level pattern. Consider both too-easy recognition and repeated inability to retrieve; no prescribed percentage decides this automatically.
4. Put reminders in a learner-controlled calendar or use a real scheduling tool only when it is actually available and invoked. A conversational promise is not a scheduled task.

Spacing research supports attention to timing, but its reported task and delay conditions do not specify an optimal schedule for every adult subject. Keep the schedule as a labeled local design choice.

## Stage5 Check retention and changed context application

1. At the planned time, collect an independent response under declared resources before reopening the prior answer. Record actual timing or explicitly mark it unknown.
2. Use a task in a changed representation or context when application matters; state what changed. Mere replacement of names or numbers may test only a narrow variation.
3. Compare retention and application separately. A remembered definition is not evidence of broad transfer, and one failed response does not show that the whole strategy is ineffective.
4. Keep the original attempt, corrections, exposure and later outcome as different events. Decide what to retain, revise or teach again using the evidence rather than the length of the chat history.

For a more consequential conclusion, use the [evaluation Practice](evaluation-of-ai-assisted-learning.md), whose core distinction is observation versus interpretation. No pass/fail learning certification is produced here.

## Comparison and scope limits

Retrieval, additional study, total time and task framing are not interchangeable. The retrieved research includes a comparison challenge to broad claims of superiority over concept mapping. The Practice therefore does not promise that recall always wins, nor treats source citation as evidence that an AI implementation worked.
