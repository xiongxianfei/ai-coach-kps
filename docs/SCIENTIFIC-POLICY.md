# Scientific scope and source alignment

## Key takeaway

Keep evidence-based scientific meaning separate from authored AI coaching decisions and learner outcomes.

## Summary

This document combines the domain scope, academic source-alignment policy, adult learner boundaries, and evidence limits. The five KPS file roles remain an authoring convention, not an educational theory. Original coaching workflows belong in Practices.

## Academic source alignment policy

The following source relationships govern independently reusable scientific objects; the authored AI coaching workflows remain separate.

## Admission by role

| Role | Admission basis | Not sufficient |
|---|---|---|
| Concept | Located scholarly characterization or definition | A fashionable term with an unrelated citation |
| Principle | Scoped empirical result or supported methodological relationship | A normative coaching rule written as a declaration |
| Model | An identified published representation, with a faithful subset and limits | A newly invented coaching cycle given a theorist's name |
| Method | A recognizable published operation and inspected procedural basis | An original prompt chain presented as a validated intervention |
| Practice | Explicit KPS application synthesis with usable actions | A list of links or a claim that it was empirically tested |

No standalone original workflow Models or Methods are included. Local prompt contracts, aid categories and record schemas are specifications or Practice content. They are not scientific Principles.

## Alignment records

Each non-Practice object declares source_alignment with a Reference ID, a documentation relation and an actual passage locator. Allowed relations are definition-paraphrase, scoped-empirical-finding, methodological-relationship, published-model-subset and published-procedure-summary. The published-model-subset relation explicitly describes an academic framework rather than a standards-body model; this is a domain profile, not silent equivalence to Core's standard-model-subset relation.

These declarations do not express formal ontology equivalence. Named sources support meanings only to their inspected extent. Source-defined scope takes precedence over local paraphrase.

## Academic naming

Use source-grounded kebab-case paths and recognized names where faithful. Preserve related-but-different meanings: retrieval is not spacing; metacognition is not all self-regulated learning; self-explanation is generated by the learner rather than supplied by AI. Academic hyphens can remain in canonical_name and prose; display headings follow the conservative Markdown profile.

Pieschl, not Schraw, authored the inspected calibration paper. A generic instruction loop is not Zimmerman's cyclical model. The latter is not included because an original source was not inspected sufficiently for admission.

## Evidence and originality

Each source record states publication identity, access extent, locators, contribution and nonclaims. A theoretical or review source can define a concept without proving an intervention effect. All AI adaptations and prompt wording remain provisional. Normative commitments to consent, privacy and access are policy choices, not invented empirical findings.

## Tests and review

The domain tests check declarations, targets, role relations and explicit limits. They cannot establish faithful paraphrase, adequate evidence or actual learning. No automated promotion to reviewed status is allowed in this draft.

## Independent adult learning scope

The adult learner retains authority over goals and assistance, while scientific claims remain provisional and subject to source applicability.

## Included work

Conceptual understanding, safe procedural learning, learner-generated explanation, retrieval, feedback, reflection and evaluation. Subject expertise remains necessary even though the workflow is domain-independent. Applications can use reading, mathematics or coding, but this package does not automatically validate the subject material.

New-subject coaching starts with a compact panoramic orientation, followed by a goal-specific concept map and an adaptive instructional sequence. Returning learners may reuse a checked overview. Panoramic coverage need not be exhaustive, and a conceptual relation is not a proven learning prerequisite. Planning status, source support and learner-performance evidence remain separate.

## One small task before more content

The default immediate unit is one bounded learning task with an observable output and a checking criterion, situated in the larger goal where useful. The panoramic overview should locate that goal without becoming a mandatory comprehensive lecture. Day labels and study durations are adjustable scheduling decisions, not KPS Practice stages or universal learning laws. Sometimes an integrative task is needed; decomposition must preserve meaning. See [the next-task guide](../guides/LEARNING-WORKFLOW.md).

## Roles and consent

The AI proposes tasks, explanations, hints or feedback; the adult chooses whether to use them. The learner may request a full explanation, challenge the criterion, change a goal, pause or stop. Answer help is recorded, not moralized. No fixed learner profile, diagnostic label or ranking is generated.

## Exclusions

This is not psychotherapy, medical/legal/financial guidance, professional safety training, certification, student grading, employee assessment, or an autonomous tutor application. Do not use the package to override qualified professional judgment or institutional assessment rules. Physical skills may require in-person supervision that a chat cannot provide.

## Human learning and AI implementation

The scholarly library concerns human learning and instruction. AI use is a proposed application unless a specific study actually investigates it. The package does not claim access to hidden model reasoning, persistent memory, web browsing, automated reminders, audio analysis or code execution merely because a prompt requests them.

## Evidence conditions

Assisted task completion, immediate independent performance, delayed retention and changed-context application are recorded separately. Unknown intervals and missing responses remain unknown. A grade from the same AI that supplied the answer is not independent verification. Retain access accommodations while specifying answer-generating assistance.

## Research scope

The source search was targeted to the five Practices, not systematic or exhaustive. Selected academic sources span research designs and populations. Adolescent and classroom evidence has explicit indirectness for independent adults. Named cognitive and assessment Models are limited source-faithful summaries, not a new theory of the learner or a causal model of an LLM.
