# Constructed adult learning example

## Key takeaway

An inspectable example can clarify outputs without inventing a completed learner session.

## Summary

This unit-cost example illustrates the four Practices. It is fully synthetic and does not report a learner, an AI run or educational effectiveness.

## Target and reference relation

Target: compare two quantities on a common basis and justify the calculation. The constructed rule is unit cost = price / quantity, with quantities expressed in the same units. No external shopping decision or financial recommendation is being made.

For A, $6 divided by 750 g is $0.008 per g, or $0.80 per 100 g. For B, $7.20 divided by 1,000 g is $0.0072 per g, or $0.72 per 100 g. Total price alone does not answer this constructed per-unit question.

## Coaching choices

| Point in a proposed session | Authored action | What must not be inferred |
|---|---|---|
| Learner chooses the target | Ask for an explanation of the quantity basis | A goal statement is not prior competence |
| An attempt is available | Preserve it and any hints | A corrected replacement is not the original |
| The relation is unclear | Offer a common-unit table or worked analogous example | A hint proves neither diagnosis nor effectiveness |
| A new response is produced | Check calculation and justification | One success is not general mastery |
| A later occasion is planned | Record intended interval separately | A plan is not retained learning |

## An example prompt and response boundary

```text
Coach prompt proposal: Compare A and B per 100 g. Write your calculation
and justify the unit before I show an answer. A calculator is allowed.
Learner response: not recorded.
Coach evaluation: not performed.
```

The source of the arithmetic criterion is the declared constructed rule and its deterministic calculation, not a fabricated citation. If the learner has already read this page, these exact values are unsuitable for a clean unexposed test; use an independently prepared comparable task and record prior exposure.

## Retention and transfer plan

A later independently answered package comparison would supply a limited retention observation. A new ratio context could examine application if the relevant reasoning is specified. These are plans only; the interval, response and outcome remain unobserved. A broader causal claim about the AI would require an appropriate comparison and cannot be extracted from this example.

## Other subject applications

In programming, a learner can compare an original function, supplied hints and a separately executed test suite; passing one test does not prove correctness generally. In historical reasoning, a claim may require corroborated primary sources and a multi-criterion argument rather than a binary answer. These application sketches require their own subject references and assessment design before use.
