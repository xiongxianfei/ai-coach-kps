# Learning Performance Distinction

## Key takeaway

Performance observed during assistance is not interchangeable with durable learning.

## Summary

Immediate performance, delayed retention and changed-context application answer different questions. The inspected review abstract supports this distinction but not a universal mastery cutoff.

## Definition and distinctions

Performance is the response observed under specified conditions. Learning refers to relatively durable change in capability, inferred rather than directly seen. An immediate successful response with an answer visible is different evidence from an independent response after a known interval.

## Constructed example

A learner repeats an AI explanation correctly, then cannot explain a new example without it. These are two observations, not proof of zero learning or mastery. Repeating an item can test memory for that item; a new representation asks a different transfer question.

## Scope and limits

There is no single delay that universally distinguishes learning from performance. Record the interval, task, preceding exposure and help. Independence from answer-generating assistance must not mean removing access accommodations.
