# Scope and application boundaries

## Key takeaway

The primary user is an independent adult pursuing a low-stakes learning goal with fallible AI assistance.

## Summary

Coaching means an educational interaction in which the learner retains control of goals, assistance and evaluation. This is an explicit project scope, not a universal definition of coaching or an endorsed professional credential.

## Included work

Conceptual understanding, safe procedural learning, learner-generated explanation, retrieval, feedback, reflection and evaluation. Subject expertise remains necessary even though the workflow is domain-independent. Applications can use reading, mathematics or coding, but this package does not automatically validate the subject material.

New-subject coaching starts with a compact panoramic orientation, followed by a goal-specific concept map and an adaptive instructional sequence. Returning learners may reuse a checked overview. Panoramic coverage need not be exhaustive, and a conceptual relation is not a proven learning prerequisite. Planning status, source support and learner-performance evidence remain separate.

## Roles and consent

The AI proposes tasks, explanations, hints or feedback; the adult chooses whether to use them. The learner may request a full explanation, challenge the criterion, change a goal, pause or stop. Answer help is recorded, not moralized. No fixed learner profile, diagnostic label or ranking is generated.

## Exclusions

This is not psychotherapy, medical/legal/financial guidance, professional safety training, certification, student grading, employee assessment, or an autonomous tutor application. Do not use the package to override qualified professional judgment or institutional assessment rules. Physical skills may require in-person supervision that a chat cannot provide.

## Human learning and AI implementation

The scholarly library concerns human learning and instruction. AI use is a proposed application unless a specific study actually investigates it. The package does not claim access to hidden model reasoning, persistent memory, web browsing, automated reminders, audio analysis or code execution merely because a prompt requests them.

## Evidence conditions

Assisted task completion, immediate independent performance, delayed retention and changed-context application are recorded separately. Unknown intervals and missing responses remain unknown. A grade from the same AI that supplied the answer is not independent verification. Retain access accommodations while specifying answer-generating assistance.

## Research scope

The source search was targeted to the five Practices, not systematic or exhaustive. Selected academic sources span research designs and populations. Adolescent and classroom evidence has explicit indirectness for independent adults. Named cognitive and assessment Models are limited source-faithful summaries, not a new theory of the learner or a causal model of an LLM.
