# Changelog

## Key takeaway

Version 0.2.0 adds two-level conceptual orientation and adaptive planning without claiming a complete field survey.

## Summary

The package is independent of earlier English and Learning and Teaching KPS work. It adopts the steps-first and source-alignment direction of Core 10.2.0 without relabeling old invented workflows as academic theory.

## Version 0 3 0

Reduce the root from 31 files to 14 while retaining the five Practices, the supporting academic library, 17 source records, generated evidence and review views, and the pinned KPS 10.2.0 contract and byte-identical validation tools. Consolidate one-task guidance with plan guidance, scientific policy with scope, validation with compatibility, and navigation with the diagram audit. Move all generated views under `generated/`, update relative links and generators, and record breaking document paths for external links in `docs/VALIDATION.md`. This is a publishing/layout change, not new evidence for coaching effectiveness.

## Version 0 2 1

Refine all five Practices around one meaningful, independently checkable **next learning task** at a time, with optional rather than compulsory subject-map setup. Add a supporting one-task guide and a constructed Day 1 example. Extend the optional planning record with one `next_task` selector and private session records with backward-compatible plan/task identifiers, plus declaration-only tests. No new independent academic knowledge object, universally optimal study duration, observed result or experimentally validated AI intervention is claimed. The Core 10.2.0 pin and its unchanged authoring tools remain fixed.

## Version 0 2 0

Add a fifth Practice for panoramic orientation, goal-specific Concept Mapping and adaptive instructional sequencing. The original four Practices retain their anchors and connect planning to actual learning episodes and evidence. Add the Concept Map Concept, Concept Mapping Method, two source records relative to 0.1.0, blank and constructed planning records, and a read-only plan-declaration checker. The resulting library has 21 objects and 17 Reference records. The complete workflow remains KPS-authored and provisional; no validated adult learning progression is claimed.

## Version 0 1 0

Four Practices with 22 stages; 14 supporting academic objects; fifteen source records; source-to-Practice evidence map; generated navigation; a blank private record and a declaration checker. Upstream 9.1.0 structure tooling is unchanged.

## Quality status

All authored knowledge remains provisional. No independent scientific review, real learner outcome or model-compliance result is claimed. Repository publication, tests and any later merge are separately verifiable events.
