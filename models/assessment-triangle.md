# Assessment Triangle

## Key takeaway

Assessment connects a model of cognition, observations and their interpretation.

## Summary

This is the named NRC assessment framework, represented as a mutually dependent triad. It is not a pipeline that converts any response automatically into mastery.

## Purpose and representation

```text
Cognition <----> Observation
     \             /
      \           /
       Interpretation
```

Every side means design dependence, not causal order. Cognition specifies the target competence; observation specifies what tasks elicit evidence; interpretation explains what responses justify inferring.

## Constructed interpretation

For comparing unit prices, the target can be reasoning about cost per common unit. Asking only for a remembered formula yields different evidence from explaining an unfamiliar package comparison. A correct number alone may not distinguish conceptual understanding from an accidentally successful procedure.

## Assumptions and limits

Subject-specific criteria are indispensable. The framework does not provide a universal scoring scale, and an AI judgment is itself an interpretation to check. Task conditions and possible alternative explanations limit an inference.

## Evaluation

Before using a task, state the target and the response features expected to support it. When the response is ambiguous, revise the observation or narrow the inference rather than manufacture a certainty score.
